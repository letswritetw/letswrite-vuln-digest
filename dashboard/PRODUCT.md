# 資安戰情室儀表板

## Register
product

## Platform
web

## 使用者與用途
工程師與專案維護者每天查閱 n8n 產生的公開資安情報：先看「今天要做的事」（要查核哪個產品、官方修補版本、建議負責角色、相關 OWASP Top 10:2025 類別、CWE 的風險與處理方式），其餘情報收在例行更新與知悉即可，可搜尋 CVE／CWE、檢視官方來源、查找歷史日報。僅供閱讀，無掃描、修補或額外 AI 呼叫。

## 設計方向
全部使用 Balsa UI 原生元件與預設主題（見 DESIGN.md），跟著電腦的淺色／深色模式切換，採清楚的繁體中文標籤、可鍵盤操作、響應式版面與手動重新整理。避免把情報查核優先級畫成使用者資產的實際曝險，明確標示未分析及待確認。

## 資料契約
讀取 schemaVersion 1 JSON（含選填的 actionPlan、cweGuides 與分類欄位），不解析 Markdown 做統計；相容年月目錄與舊平面目錄。零筆、缺少報告、損毀及過期資料分開呈現。Markdown 僅作安全閱讀與下載。Docker 使用唯讀報告掛載，對外埠為 3030。
